# Frontend - Next.js (Minggu 9–10)

Antarmuka blog interaktif berbasis Next.js App Router yang menerapkan Atomic Design dan terhubung ke Strapi CMS via REST API.

## Tech Stack
- Next.js (TypeScript)
- Tailwind CSS

## Implementasi Atomic Design
- Atoms: components/atoms/Badge.tsx (Label kategori)
- Molecules: components/molecules/ArticleCard.tsx (Kartu artikel)
- Organisms: components/organisms/ArticleList.tsx (Daftar kartu artikel)

## Cara Menjalankan
- cd frontend-nextjs
- npm install
- npm run dev
- Buka browser di http://localhost:3000
